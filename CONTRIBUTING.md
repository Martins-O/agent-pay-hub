# Contributing Guide (Outline)

AgentPay Hub welcomes contributions from the community. This guide will document:

- Project governance, branching, and release strategy.
- Commit message conventions (Conventional Commits).
- Development environment setup and tool versions (pnpm, TypeScript, Rust if applicable).
- Code style guidelines for server (TypeScript), SDK (TypeScript), and dashboard (React + Vite).
- Testing requirements: unit, integration, devnet chain tests, coverage thresholds, linting.
- Pull request checklist and CI expectations.
- Issue reporting templates and triage workflow.

Full details will be added as the codebase is scaffolded.
